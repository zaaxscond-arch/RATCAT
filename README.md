### 📱 About RATCAT

RATCAT is an advanced Remote Access Toolkit designed for Android devices with modern features. Connect via QR code scan and control devices remotely from Termux.

### ✨ Features

| Feature | Description |
|---------|-------------|
| 🔦 **Flashlight** | Turn device flashlight ON/OFF remotely |
| 🎵 **Music Player** | Play YouTube music links remotely |
| 🔒 **Screen Lock** | Lock screen with custom unlock code |
| 📺 **Screen View** | View device screen via localhost |
| 🖼️ **Wallpaper** | Change wallpaper via image URL |
| 🔔 **Notifications** | View incoming notifications in real-time |
